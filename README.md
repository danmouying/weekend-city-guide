# 周末去哪儿 · Weekend City Guide

面向大学生的周末城市探索网页作品。以杭州为示例，根据兴趣、预算、天气情景和同行人数，帮助用户完成「发现活动 → 安排行程 → 邀请朋友 → 打卡分享」。

## 在线体验

[打开网页版](https://danmouying.github.io/weekend-city-guide/)

## 已实现功能

- **发现**：6 类活动、关键词搜索、人均预算、同行人数、晴天 / 雨天筛选，活动详情和片区地图。
- **周末计划**：半日 / 一日自动安排、手动添加、移除和调整顺序；计算活动总费用与含交通预留的总时长，提示超预算或超时。
- **一起出发**：分享可恢复的行程快照链接，本机投票演示，填写昵称、集合地点与时间。
- **我的足迹**：收藏、照片打卡、实际费用和感受；根据记录生成可编辑的文字攻略，确认后复制。
- **适配**：桌面与手机布局、键盘焦点、弹窗 Escape 关闭、空结果提示、复制失败时手动复制。

## 作品边界

这是可以交互的前端课程作品，无账号、后端数据库和实时 AI 服务。推荐使用明确的筛选与预算规则，**不是调用大模型**。

活动、票价、距离、容量、交通时间、演出、市集与天气均为示例，不构成真实出行信息。天气选择是情景模拟；图片并非活动现场，来源和许可证见 [图片来源页面](credits.html)。

收藏、计划、报名、投票与打卡保存在当前浏览器 `localStorage`。不同用户、设备之间**不会同步投票和报名**。分享链接只传递活动编号、半日 / 一日与同行人数，不含昵称、集合地点、打卡文字和照片。打开链接可以重建计划快照。清理浏览器数据会清除本机记录；最多保留最近 30 条打卡。

## 本地运行

安装 Node.js 20 或更新版本。项目无第三方运行依赖，不需要 npm install。

```bash
git clone https://github.com/danmouying/weekend-city-guide.git
cd weekend-city-guide
npm run dev
```

浏览器打开 http://127.0.0.1:4173 。不要直接双击 HTML；浏览器的 ES 模块需要 HTTP 服务。

## 检查

```bash
npm run check
npm test
npm run build
```

测试覆盖：雨天筛选、预算为零、人数限制、搜索、行程累计预算 / 时长约束、分享参数校验、重复活动计费。

源码集中在仓库根目录，GitHub Pages 直接发布 main 分支根目录。`npm run build` 校验网页文件，并复制到本地预览使用的 `dist/`；构建目录不需要提交。修改后再次运行该命令并刷新本地网页。

## 关键文件

| 文件                  | 作用                           |
| --------------------- | ------------------------------ |
| `index.html`     | 页面入口与导航                 |
| `styles.css`     | 视觉样式与手机适配             |
| `app.js`         | 页面渲染、交互、分享与本机存储 |
| `data.js`        | 明确标注的示例活动             |
| `core.js`        | 活动筛选、行程安排与费用计算   |
| `credits.html`   | 图片出处和许可                 |
| `server.mjs`          | 本地静态预览服务器             |
| `core.test.mjs` | 核心规则测试                   |

## 后续可扩展

接入经授权的真实活动 / 天气服务，以及账号、数据库和多人同步，即可继续向真实应用演进。不要把 API Key 放进网页代码或提交到仓库。
